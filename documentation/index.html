What is DecentEdu?

DecentEdu is a ground-up rebuild of the “Safe Eduman” school ERP, delivered as a modern Laravel API + React single-page application. It runs the full academic and administrative lifecycle of a school or college — from an applicant's admission through daily attendance, exams, result processing, fee collection and financial accounting, to certificates and the school's public website.

🏫

Multi-branch by design

One organization can run many branches (campuses). A single login can access several branches; you pick an active branch and every screen is scoped to it.

🇧🇩

Built for the BD system

Class / Shift / Section / Group model, GPA grading with the 4th-subject bonus, transfer certificates, testimonials and bilingual (English + Bangla) records.

🔐

Role & permission based

Super Admin, Admin, Accountant, Exam Controller and Teacher roles, with permissions that decide exactly which modules and actions each user can reach.
