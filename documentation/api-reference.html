API Reference

A developer's map of the DecentEdu REST API. Everything is under /api/v1, uses cookie (Sanctum) sessions, runs behind the active-branch context, and returns the same JSON envelope.

Authentication

The SPA authenticates with Sanctum cookie sessions (not bearer tokens). The flow:

  1. GET /sanctum/csrf-cookie — obtain the XSRF cookie.
  2. POST /api/v1/auth/login — with credentials; a session cookie is set.
  3. All later requests send the session cookie + X-XSRF-TOKEN header automatically.
MethodEndpointPurpose
POST/auth/loginSign in (public)
POST/auth/forgot-passwordRequest reset link (public)
POST/auth/reset-passwordSet new password (public)
GET/auth/meCurrent user + branch + permissions
POST/auth/logoutSign out

GET/auth/sessionsList active sessions

POST/branch/switchChange active branch

Conventions

Base path
All endpoints are prefixed /api/v1.
Middleware
Authenticated routes run behind auth:sanctum + branch (active-branch context).
Permissions
Each module group requires its *.manage (or *.view) permission.
Setup resources
Reference tables share a generic {resource} endpoint constrained to a slug whitelist.
Throttling
Bulk import, SMS send and report endpoints are rate-limited.

Response envelope

// Success
{ "success": true, "message": "…", "data": { … }, "meta": { … } }
// Error
{ "success": false, "message": "…", "error_code": "…", "errors": { "field": ["…"] } }
