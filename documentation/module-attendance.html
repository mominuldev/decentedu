Attendance

Attendance covers both students and staff. Marks can be entered manually or ingested automatically from biometric devices, with holidays and time rules deciding what counts as present, late or absent — and absentee notifications going out to guardians.

Menu: Attendance Permission: attendance.manage Typical user: Teacher / Admin

Two sub-systems

Student attendance

Taken per class config for a date. Statuses: present, absent, late, leave, half-day.

Staff attendance

Employee daily attendance, typically fed from device punches.

Taking attendance

  1. Pick the class & date
    Choose a class config (and section) and the day.
  2. Mark each student
    Present / absent / late / leave / half-day — quickly across the roster.
  3. Save
    Records are stored; an existing day's attendance can be updated.
  4. Notify (optional)
    Send guardians of absentees an SMS using a template. — Messaging

Biometric devices

For schools using fingerprint / card devices, DecentEdu ingests raw punches and resolves them into daily attendance.

Devices
Register each physical device.
Device maps
Map a device's user ID to a student or employee, so a punch is attributed to the right person.
Time configs
Define expected in/out times and the late threshold.
Punch processing
Raw punches are received, then processed into resolved present/late records for the day.
Device punch→ Map to person→ Apply time config→ Daily attendance

Holidays

Holidays mark non-working days so attendance and reports don't flag those dates as absences. Maintain the holiday calendar per branch.

Reports

Daily attendance reports for students and staff summarize presence, absence and lateness — filterable by class and date range, and printable.
