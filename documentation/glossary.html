Glossary

Plain-language definitions of the terms used across DecentEdu — both system concepts and Bangladeshi-education vocabulary.

Academic structure

Organization
The top-level entity that owns one or more branches (e.g. a school group).
Branch
A single campus/school. All operational data is isolated per branch.
Academic Year / Session
A school year (e.g. 2026). One per branch is the current session; enrolment, exams and fees are scoped to it.
Class
A grade level (Six … Ten, or college classes).
Shift
A daily time band such as Morning or Day.
Section
A division within a class (A, B, C).
Group
A senior-class stream — Science, Business Studies, Humanities.
Category
A student classification such as General or Residential.
Subject
A taught subject (Bangla, English, Mathematics, ICT…).
Class Config
The concrete teaching unit = Class × Shift × Section. The hub everything references.
Enrolment
A student's placement (class config + roll) for a specific academic year.
Roll
A student's class roll number, unique within a class config for a year.

Examinations

Short Code
A label for a mark component (CQ, MCQ, Practical…).
Mark Config
A subject's components, their totals and pass marks for an exam.
Grade Scale
The mark-range → letter grade → grade point table, defined per class.
Grade Point
The numeric value of a letter grade (e.g. A+ = 5.0).
GPA
Grade Point Average across a student's compulsory subjects, plus the 4th-subject bonus.
4th Subject
An optional subject that can only help: it adds max(0, gradePoint − 2) to the GPA total but isn't counted in the divisor.
Merit Process
The step that computes GPA and assigns class/section positions.
Sequential / Non-sequential
How tied positions are ranked — advance the next rank vs. skip it.
Marksheet
An individual student's result document.
Tabulation Sheet
The whole class's results in one grid.
Admit Card
A student's exam entry pass, with instructions and signatures.
Seat Plan
Assignment of students to exam-hall seats.

Finance

Fee Head / Sub-head
Head = a grouping (Tuition); sub-head = a billable line (January tuition).
Fee Config
The payable amount for a sub-head, per class config, per year.
Waiver
A discount that reduces a student's payable.
Fine
A flat late charge applied once after a due date passes.
Student Fee / Dues
The assessed amount a student owes: payable − waiver − paid (+ fine).
Collection / Receipt
A recorded payment with a sequential receipt number.
Ledger Account
An account in the chart of accounts (Cash, Tuition Income…).
Voucher
A financial transaction made of debit/credit entries. Types: receive, payment, contra, journal.
Double-entry
Every voucher's debits equal its credits — the books stay balanced.
Trial Balance
All accounts' debit/credit totals — proof the ledger balances.

People & documents

Guardian
A student's parent/guardian and contact for notifications.
Migration (students)
Year-end promotion of students — promote, general (re-enrol) or push-back (reverse).
Transfer Certificate (TC)
The official leaving certificate issued when a student departs.
Testimonial
A character/attendance testimonial document.
Subject-Teacher
An assignment linking a teacher, a subject and a class config.
Punch
A raw biometric device event, later resolved into daily attendance.
Device Map
A mapping from a device user-ID to a student or employee.

CMS & website

Page
A website page built from stacked content blocks.
Block
A reusable content section (hero, rich text, gallery, CTA, FAQ…).
Post
An article/news item, categorized by taxonomies.
Taxonomy / Term
A classification (taxonomy) and its values (terms) used to organize posts.
Notice / Event
An announcement / a dated calendar entry published to the site.
Redirect
A rule sending an old URL to a new one.
SEO fields
Meta title, description and social-preview data per content item.

Platform & security

Multi-branch / Tenancy
Running many branches on one system with row-level isolation by branch_id.
Active branch context
The branch a request operates in, set per request and scoping all data.
Role
A named bundle of permissions (Admin, Accountant, Teacher…).
Permission
A single capability, e.g. fees.manage.
RBAC
Role-Based Access Control — permissions granted via roles, scoped per branch.
Sanctum
Laravel's cookie-session authentication used by the SPA.
Soft delete
Marking a record deleted (reversible) rather than removing it permanently.
Report Artifact
An asynchronously generated report file (PDF/Excel) you poll for and download.
Audit log
A record of who did what and when, for sensitive operations.
