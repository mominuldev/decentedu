Routines

Routines are the school's timetables. You define the periods of the day, then build a class routine — which subject and teacher occupies each period for a class — and view the same data as a teacher routine for any staff member.

Menu: Routines Permission: routines.manage Typical user: Admin / Teacher

Periods

A period is a time slot in the school day (e.g. 1st period 09:00–09:45). Define the periods once per branch/shift; the routine grid then has a column for each.

Class routine

For a chosen class config, the routine is a grid of day × period. Each cell holds a subject, the assigned teacher and (optionally) a room. Building it uses the subject-teacher assignments so you pick from valid teacher/subject combinations.

Day (Sun–Thu)× Period→ Subject + Teacher + Room
🧭

Because both class and teacher routines read the same slots, DecentEdu can surface clashes — the same teacher booked in two places at once — helping avoid double-booking.

Teacher routine

Flip the same data around to see a single teacher's week: every class and subject they teach, period by period. This is what teachers get as their personal timetable.

Printing

Both class and teacher routines render to a clean, branded print page suitable for handing out or posting on the noticeboard.

Exam routines

Exam schedules (date, time and room per subject) are managed in the Examinations module, since they belong to a specific exam rather than the weekly class timetable.

At the API level

GET/POST/PUT/DELETE  /api/v1/routines/periods
GET   /api/v1/routines/class-configs/{id}/options   # valid subjects/teachers for the grid
GET   /api/v1/routines/class-configs/{id}           # the class routine grid
GET   /api/v1/routines/teachers/{employeeId}        # a teacher's routine
POST  /api/v1/routines                              # add a slot
PUT   /api/v1/routines/{id}   DELETE /api/v1/routines/{id}
