Getting Started

This page walks a brand-new user through signing in, choosing a branch, and understanding the two ideas that frame every screen in DecentEdu: the active branch and the active academic year.

Signing in

DecentEdu is a web application. Open the school's DecentEdu URL in any modern browser and you land on the Login screen.

  1. Enter your email & password
    Credentials are issued to you by an administrator. There is no public self-registration.
  2. Sign in
    A secure session cookie is created. You stay signed in until you log out or the session expires.
  3. First-time / reset password
    If your account was flagged for a reset, you must set a new password before continuing. Forgot your password? Use Forgot password to receive a reset link.
🔑

Demo credentials. On a seeded demo database you can sign in as demo@decentedu.test / password (an Admin with access to all demo branches).

Selecting a branch

A single user account can belong to several branches (campuses) of the same organization. Because all data is isolated per branch, the system always needs to know which branch you are working in.

  • If you belong to only one branch, it is selected automatically — you go straight to the dashboard.
  • If you belong to several branches, your default branch is used first; you can switch at any time from the top bar.

Switching branch re-scopes everything: student lists, fees, exams, reports — all now show data for the newly selected branch, and your permissions for that branch take effect.

⚠️

Data never crosses branches. A student, receipt or mark that belongs to Branch A is completely invisible while Branch B is active. This is enforced on the server, not just hidden in the interface — see Multi-branch isolation.

The active academic year

Alongside the active branch, each branch has a current academic year (session, e.g. 2026). A student's class, section and roll are recorded per year, so the active year determines which enrolment, attendance, exams and fees you see. At year-end, students are promoted into the next year through the Student Migration tool rather than by editing records in place.

Finding your way around

The interface has three consistent regions:

Left sidebar
The module menu, grouped by area (People & Academics, Daily Operations, Finance, Engagement, System). Only modules you have permission for appear.
Top bar
Branch switcher, notifications, light/dark theme toggle, and your profile menu (change password, sign out).
Main area
The current module. Most modules are a hub page with tabs; list screens open a full form page to create or edit a record (not a pop-up).

Tabs, lists and forms

A typical module (say Fees or Examinations) is a single page with tabs across the top — one tab per sub-feature. Inside a list you'll find search, filters and pagination. Creating or editing a record (a student, an application, a CMS page) navigates you to a dedicated form page and returns you to the exact tab you came from when you save or cancel.

What you can do depends on your role

DecentEdu is permission-driven. An Accountant sees Fees, Accounting and Reports; a Teacher sees Attendance, Routines and Examinations; an Admin sees everything in their branch. The full matrix is in Roles & Permissions.
